A security and maintenance release. The wallet's own code is unchanged; it now ships on a patched Electron.

## Security

- **Electron 44.11.6** (from 44.5.1). It carries the mitigation for the compromised eMudhra intermediate certificates ([GHSA-jr5w-w6x2-84p9](https://github.com/advisories/GHSA-jr5w-w6x2-84p9)). Electron is the runtime inside every installer, so this fix reaches you only through a new download.
- **follow-redirects 1.16.3** (from 1.16.1), for [GHSA-mrwp-f3q8-3g9p](https://github.com/advisories/GHSA-mrwp-f3q8-3g9p). JSWallet follows no redirects, so it was not exposed; the update clears the advisory.

## Build

- **Linux:** the `.rpm` builds on rpm 4.20 and later, which the release runners now use.
- Development and CI dependencies are current (Vite, jsdom, the lint plugins, the GitHub Actions the workflows pin).

|---|---|

| Linux x64 | `jswallet_1.2.0_amd64.deb`, `jswallet-1.2.0-1.x86_64.rpm` |

Check a download with `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`.

**The installers are not code-signed yet.** The system warns the first time you open them:
- **macOS:** System Settings › Privacy & Security › **Open Anyway**. On macOS 14 and older, right-click › **Open**.
- **Windows:** SmartScreen › **More info** › **Run anyway**.

Windows signing (through the SignPath Foundation) and Apple notarization are planned.

JSWallet is an educational wallet and runs on testnet4 by default. It is not production software.
